# 大喜利ダイス：演出・音響の実装レビュー

> レビューの訂正：本記録は当時の動作・表示確認の結果。READMEに明記された「若手芸人」という主題との一致を見落としていたため、駅・列車のデザインが適切であるという評価は撤回する。ユーザーの指摘を受けた[再設計案](../superpowers/specs/2026-09-26-comedian-presentation-design.md)を参照。過去のテスト成功は新しいデザインの検証を意味しない。

2026-09-26。タイトルから優勝までを「東京の駅から出かける旅」の表現で統一。既存の地図・ルール・オンライン権限を保ち、画面と音の層を追加した。

## 参考と独自性

- [桃鉄ワールド公式](https://www.konami.com/games/momotetsu/world/play.php)：目的地と到着報酬を主役にする画面構成。
- [マリオパーティ公式](https://www.nintendo.com/jp/switch/a7hla/sugoroku/index.html)：場面ごとの主役と周辺情報の優先順位。
- 公式掲載画像を目視し、構成の参考にした。既存キャラクター・画像・旋律は流用していない。列車・街並み・サイコロ・表彰メダルは専用SVG、BGMは独自の16小節を2曲作成。

## 実装した場面

| 場面 | 表現と操作 |
| --- | --- |
| タイトル | 立体的な文字組み、東京の街並み、列車の入線、2枚の乗車券型ボタン、展開式の遊び方 |
| 人数設定 | 1〜4人の乗車カード。番号・名前・人/CPU・性格を同じカードに配置 |
| オンライン入口 | 共通の名前入力と、部屋作成/コード参加の別々の入口 |
| 待機室 | 実際の参加者から4席を表示。ホスト・接続状態・空席・開始条件・招待操作を明示 |
| 手番・回答 | 列車で手番を紹介。回答中は入力を優先し、BGMを抑える |
| 採点・結果 | 審査席の短い演出、600ms後のサイコロ/点数と同期する音。動き軽減時は即表示 |
| 青/赤チャレンジ | 賞金とピンチを専用の見出し・色・マークで区別 |
| 到着・優勝 | 駅名看板、賞金、有限の紙吹雪。優勝は金色の表彰と順位 |
| 音の設定 | BGM/効果音の個別音量、一括ミュート、端末内保存。最初の操作で再生開始 |

音は状態変化を観測するだけでゲームアクションを発行しない。再接続・同一スナップショット・アンマウントで古い結果音が再生されないようにした。タイトルへ戻る際には予約済みファンファーレも停止する。

## 自動検証

- `npm test --prefix app -- --maxWorkers=2`：22ファイル、100テスト成功。
- `npm run build --prefix app`：TypeScriptと本番ビルド成功。
- `npm run lint --prefix app`：成功。
- 最初の全並列実行では、優勝まで進む既存の通しテストが5秒の上限を超過。単独で4/4成功、並列数を2に抑えた全件で100/100成功。テストの制限時間や期待値を緩めていない。
- 既存の勝利までの進行、入力/IME、オンライン観戦・切断と、新規の待機室・音設定・結果音・ミュート・背景停止/復帰・予約清掃・動き軽減を検証。
- 音の不具合と動き軽減は、失敗する回帰テストを先に確認してから修正した。

## 実画面とブラウザ音声

- PC幅、390×640でタイトル、人数設定、オンライン入口、実待機室、手番、回答、結果、青赤、到着、採点失敗、優勝を確認。
- スマホ幅の長文回答は回答欄内でスクロールし、確定操作を画面内に残す。4人設定と待機室は縦スクロールで全操作に到達できる。
- 844×390の短い横画面でも独立レビューを実施。タイトルの2つの入口は画面内に収まり、2人/4人設定とオンライン入口は縦スクロールで全操作へ到達。減額の確定ボタンは常時表示、優勝はパネルのスクロールでタイトルへ戻れる。重なりや操作不能な見切れなし。
- 2つのブラウザ画面でローカルWorkerの部屋を作成・参加・開始。お題、同じ回答、点数、移動、青チャレンジの同期と、観戦側に操作が出ないことを確認。確認用プレイヤーは退出済み。
- 動き軽減設定の結果画面で、点数と確定ボタンの表示を確認。自動テストでは待ち時間なしの表示を検証。
- ブラウザでAudioContextが最初の操作後にrunningになることを確認。BGM/効果音の操作とミュートを確認。背景停止/復帰と予約音清掃は音声エンジンのテストで検証。
- ブラウザのOfflineAudioContextで実装の全16小節を音声データに変換。メニュー約34.10秒、盤面約37.92秒（末尾を含む）。ピークはそれぞれ0.1770/0.1982、RMSは0.0443/0.0366で無音やクリッピングなし。
- 旋律・和音・ベース・打楽器に休符、スウィング、強弱を設け、単音を等間隔に鳴らすだけの構成を避けた。音声データの検証は、人がスピーカー/イヤホンで聴いた評価とは別である。

## 独立レビューと修正

実装担当とは別のレビューでコードと実画面を確認。

1. 地図の進路ボタンがホバーでずれる：共通ホバーのtransform上書きをやめ、独立したtranslateへ変更。
2. 切断/再接続で結果音が再生される：結果画面から音を分離し、接続状態を観測するGameAudioへ移動。回帰テストを追加。
3. タイトルへ戻っても予約されたファンファーレが鳴る：場面切替で効果音の予約を停止。回帰テストを追加。
4. スマホの減額結果で下限注記と回答者名が重なる：結果領域の固定割合の高さ制限を解消し、再読込で重なりがないことを確認。
5. 遊び方を閉じた際のフォーカスを、開いたボタンへ戻すよう修正。

列車・乗り場・席番号は操作や参加者を説明する役割を持ち、装飾用絵文字の寄せ集めになっていないことを確認。審査中の無限バウンスを廃止し、手番・結果・到着の動きに役割と終わりを設けた。PC/スマホの確認範囲に未解決の表示不具合なし。
