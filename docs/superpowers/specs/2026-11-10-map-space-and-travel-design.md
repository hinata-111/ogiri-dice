# マス間隔と移動距離を感じられるマップ表示

ユーザー依頼: マップが小さく「広く見る」の効果が弱いため、内容は維持し、マス間隔を広げて移動している感覚を強める。

- 36マス・38接続・色・地名・曲線・背景画像・目的地・ゲームルールは維持する。生成マップや表示座標のデータは編集しない。
- 通常表示の地図描画範囲を従来の約2倍にし、物理的なマス中心間の距離を広げる。全画面coverの約2.2倍を基準に、小さい横画面でも盤面幅2600px以上を目安にする。
- マス・コマ・クリック領域の見た目は大きくしすぎない。SVGのマス描画を表示倍率で補正し、間隔と駒の大きさを分離する。道路の線幅も一定にする。
- 「広く見る」は既存のcover下限まで引き、通常表示との違いを明確にする。画像外の余白を見せない既存の制約は維持する。
- 追従時は現在地と合法な隣接候補の範囲に合わせ、必要な場合だけ倍率を下げる。特にスマホの分岐で候補を確認しやすくする。地図外を出さない範囲で枠に収め、手動見回しと現在地への復帰は維持する。
- cover下限でも長い区間の候補が画面外に残る場合は、方向とマス種別を示す「← 通常マスを見る」等のボタンを表示する。押すとその候補へ見回すだけで、移動は実マスを押して行う。見回し中の案内とマップ操作ボタンを重ねない。
- コマ移動と追従は約520msの同じ時間幅で滑らかに動かす。CPUの次の一歩も表示時間を待つ。reduced-motionでは既存どおり動きを抑える。
- カメラと描画は端末内の表示状態。reducer・共有ゲームロジック・Worker・オンライン通信・入力期限は変更しない。

検証: 通常/広く見るの倍率差、隣接マス間の描画距離、スマホの候補表示、余白防止、手動見回し維持と復帰、マス/コマ/経路の中心一致。アプリ全テスト・build・lintとPC/スマホ幅の実ブラウザで確認する。
