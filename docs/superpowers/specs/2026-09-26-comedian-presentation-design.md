# 大喜利ダイス：東京の劇場を巡る家庭用ゲームの表現

2026-09-26 / 最終画像の方向性をユーザーが「ok」と承認。実装の基準。

## 正典と主題

README・map.md・v2仕様にある若手芸人の大喜利すごろく。東京の劇場とテレビ局を目指し、回答の採点が移動数になる。鉄道や社長を主題にしない。駅は既存データに含まれる中継地点として保持する。

ユーザーの確定条件：人の顔を使わない。派手なパーティー、生成画像らしい過密な描き込みと光沢を抑える。既存マップの地理を残し、Switchのすごろくにある読みやすい画面部品と立体的なマスの手触りを参考にする。

## 回答発表の表示契約

**常にマップの上にカードを重ねる。劇場内の別画面へ切り替えない。**

通常の発表：上に回答者とお題、左に大きく回答、右に点数と移動数、下に「放送作家」の講評と続行。点数は回答の評価であり、サイコロでランダムに決定したように見せない。長い回答・講評は切り捨てず、カードの本文をスクロール可能にする。スマホでもマップの余白を残し、横長の低い画面では本文をスクロールさせて操作を保つ。

青・赤の結果は既存ルールの実際の増減と変更前後の所持金、赤マスの目標点を表示。下限0円の補正、代替スコアの説明、再審査の可否を保持する。到着と優勝だけ少し大きな演出にする。

オンラインの全員回答は、30秒回答→全員採点→全員の結果を5秒間一覧→プレイヤー1から移動、という新仕様を保持。結果一覧も地図上の共通の発表ウィンドウとし、回答者・回答・点数・移動数・講評を対応させる。演出でサーバーの期限を延長しない。下書き・本文秘匿・自分の提出状態・操作権限を保持する。

## 音・動き・実装境界

既存の軽快なオリジナル音楽と音量設定を維持。列車の視覚表現は撤去。短い出現と得点発表に動きを絞り、動き軽減を守る。無限バウンスや装飾の常時揺れを作らない。

reducer、ゲーム定数、接続図、Evaluator、Workerの処理には変更を加えない。画像は背景だけで、文字・マス・コマ・HUD・カードを焼き込まない。承認画像そのものをプレイ画面へ貼らない。
