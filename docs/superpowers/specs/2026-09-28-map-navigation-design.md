# マップの見回しと移動操作

移動操作は[2026-10-18 隣接マスの直接移動](2026-10-18-direct-cell-movement-design.md)で改訂。以下の「分岐は選択と決定を残す」は旧動作であり、現在は合法な隣接マスを直接押して1歩進む。

## 追加調整: マップ外を見せず、通常表示を引く

縮小下限は画像が画面全体を覆う cover 倍率とする。操作パネルの背後も含めて画像で埋め、ドラッグは画像の四辺で止める。通常倍率は cover の1.25倍から1.05倍に変更する。「全体地図」は「広く見る」に変更し、画面を埋める範囲で最も引いた表示にする。縦画面では全マスを同時には収めず、見回して確認できる。リサイズ時も倍率を補正し、青い余白を出さない。

ユーザー承認済みのおすすめ案を実装する。通常マップと全体地図を同じカメラで扱い、ドラッグ・ホイール・ピンチ・ズームボタン・矢印キーで見回せるようにする。手動操作後はコマや手番が変わっても表示位置を維持し、「現在地へ戻る」で追従を再開する。目的地と全体表示へのショートカットを残す。

追従中はコマが安全領域を出たときだけカメラを動かす。ドラッグとタップを区別し、ドラッグ終了でマス選択や移動を発火させない。遠くのマスは詳細を見るだけで移動しない。進路が一つなら1操作で1歩進め、分岐は選択と決定を残す。

残り歩数で通れるマスを金色で強調し、詳細にも範囲内か表示する。これは停止地点の確定ではなく通過可能範囲。来た道への逆戻り制約を使い、目的地への到着で探索を終了する。

ゲーム状態・移動制約・オンライン同期・制限時間は変更しない。カメラは端末内の表示状態として管理する。狭い画面でも地図操作と移動操作を分けて配置し、ボタンとキーボードでジェスチャーを代替できる。

検証: 見回し後の位置維持、復帰、ズーム上下限、ピンチ、誤タップ防止、一本道、分岐、観戦時の移動不可をテストする。アプリ全テスト・ビルド・lintとブラウザで確認する。
