# オンライン共通お題ラウンド

状態: ユーザー承認済み。各自のスマホで同時入力し、追加お題は現行のまま維持する。

本書はオンライン対戦設計の通常手番フローを上書きする。2026-09-27追記: ユーザーの「両方で」によりローカルも同じ共通30秒ラウンドへ統一する。CPUも同じお題へ並行回答し、全員の採点後P1から移動する。1台で複数の人間を設定した場合は各人の入力欄を共通期限内に表示する。追加お題は15秒を維持する。

- 待機室の参加順を開始時にP1〜P4として固定し、毎ラウンドこの順で移動する。
- 共通のお題に全員が30秒以内に一度だけ回答する。全員提出または締切で受付終了。締切前は回答本文を全端末への配信から除外し、提出状況のみ表示する。
- 回答窓はラウンド番号で識別し、他人の提出や再接続で変わる部屋版番号とは分けて受付を検証する。移動と追加回答は従来の版番号・手番検証を維持する。
- 未回答は1点。提出済みの回答は並列にEvaluatorで採点する。遅延・重複結果はラウンド番号とプレイヤーIDで排除し、期限時には未完了分だけ3点へフォールバックする。
- 全員の結果を5秒間一覧表示し、P1から各自の点数分移動する。青赤の追加お題（15秒、金銭のみ）、到着時の目的地更新、100万円で手番終了時の勝利判定は維持する。
- 全員の移動・追加チャレンジ完了後に次の共通お題へ進む。切断時も共通締切を延長しない。
- ゲーム状態変更はgameReducerのみ。回答・採点結果はラウンドデータとして永続化し、期限は既存Durable Objectのalarmで進める。

検証: reducerの固定順・歩数保持・チャレンジ・周回・勝敗、同時送信と秘匿、締切と遅延採点、復帰、全員切断時の完走、UIの提出待ちと操作権、Worker統合テストを実施する。
