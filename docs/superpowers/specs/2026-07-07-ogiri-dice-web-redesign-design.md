# ogiri-dice Web版 全面再設計 設計書

日付: 2026-07-07
ステータス: 承認済み（実装計画待ち）

## 背景と決定事項

Unity 版の開発は、Unity Editor の操作習熟が障壁となり停止した。本設計では技術スタックを Web 技術に全面移行し、プロダクトをゼロから再設計する。

### Unity をやめる理由

1. **日本語入力**: Unity WebGL はブラウザ上の日本語 IME 入力が不安定。大喜利ゲームの核であるテキスト入力と致命的に相性が悪い。
2. **開発の自動化**: Unity の作業の多くは Editor GUI 操作（シーン配置、Inspector 設定）であり、Claude が代行できない。Web 開発ならコード記述から実行・ブラウザ検証まで全工程を自動化できる。
3. **配布**: WebGL ビルドは重くロードが遅い。Web ネイティブなら軽量でスマホブラウザでも安定する。

### 決定した前提

- **配布先**: ブラウザで一般公開(URL 共有で誰でも遊べる)
- **プレイ形式**: 1〜4 人。人間と CPU の混在可(ローカル交代プレイ)
- **コンセプト**: 「大喜利回答 → AI 採点 → すごろく盤を進む」の核は維持、細部は再設計
- **API キー**: Cloudflare Worker 経由で秘匿(クライアントに露出しない)
- **技術スタック**: React + TypeScript (Vite) + Cloudflare Pages/Workers

## ゲームルール

### コアループ — 「大喜利がサイコロ」

1. 手番プレイヤーにお題を表示する。
2. 制限時間(60 秒想定)内に回答を入力する。
3. Gemini が採点する: スコア 1〜6 + 短いツッコミコメント。
4. **スコアがそのまま進むマス数になる**(サイコロは振らない。面白さが移動力)。
5. 止まったマスの効果が発動し、次のプレイヤーの手番へ。

### 盤面

- スタート → ゴール(劇場)の一本道。30 マス前後。
- マス種別:
  - **通常**: 効果なし
  - **青**: ボーナス賞金
  - **赤**: 賞金減額
  - **イベント**: 特殊お題(縛りお題など。初期実装では最小限、後で拡張)

### 勝敗と賞金

- ゴール到達で大きな賞金。全員ゴール時点で所持金最多のプレイヤーが優勝。
- 毎回の回答スコアに応じて賞金を加算する(高得点回答ほど金が貯まる)。
- 時間切れはスコア 1 扱い + 「時間切れ!」コメント。

### CPU プレイヤー

- Gemini が回答を生成し、人間と同じ採点フローに乗せる。
- 性格パラメータ(無難/攻めた回答など)でキャラを差別化する。

## 画面構成・UX

### レイヤー構成

**すごろく盤を全画面背景とし、その上に HUD・カード・入力欄を重ねる。**

```
┌──────────────────────────────┐
│ 💰P1:12万 P2:8万   ⏱ 45s   │ ← HUD(上部固定・半透明)
│   ～～すごろく盤(全画面)～～   │
│  🟦─⬜─🟥─⬜─🎭…コマ🚶      │ ← カメラは手番コマに追従
│   ┌────────────────┐   │
│   │ お題カード(中央に浮く) │   │
│   └────────────────┘   │
│ ┌──────────────┬────┐ │
│ │ 回答を入力...      │ 送信 │ │ ← 入力欄(下部固定)
│ └──────────────┴────┘ │
└──────────────────────────────┘
```

- **盤面**: 全画面に広がるマップ(蛇行パスで奥行き感)。カメラが手番プレイヤーのコマへスムーズにパン/ズームする。
- **入力フェーズ**: 盤面をわずかに暗転+ぼかし、お題カードと入力欄にフォーカス。
- **採点中**: カード裏返し演出+「審査中…」表示。盤面はスポットライト色に変化。待ち時間をドキドキ演出に変換する。
- **結果**: ドラムロール → スコア発表 → ツッコミ吹き出し → オーバーレイが消えて盤面全開 → コマ移動をカメラ追従で見せる。
- **マス効果**: 止まった瞬間にミニポップアップ(+5万円! など)。
- タイトル・リザルトも盤面を背景に敷いたまま上にパネルを表示する(世界観の連続性)。
- スマホ縦持ち優先のレスポンシブ。

### 画面一覧

1. **タイトル画面**: ロゴ、はじめるボタン、プレイヤー設定(人数、人間/CPU、名前)
2. **ゲーム画面**: 上記レイヤー構成のメイン画面
3. **リザルト画面**: 順位、獲得賞金、ベスト回答集(高スコア回答の振り返り)

### CPU ターンの見せ方

「◯◯(CPU)が考え中…」→ 回答表示 → 人間と同じ採点演出で進行する。

## アーキテクチャ

### リポジトリ構成(モノレポ 2 パッケージ)

```
ogiri-dice/
├─ app/        React+TS (Vite) — ゲーム本体
└─ worker/     Cloudflare Worker — Gemini プロキシ
```

### フロントエンドの責務分離

```
app/src/
├─ game/          ロジック層(React 非依存の純 TS)
│  ├─ state.ts       GameState 型 + reducer(状態遷移の全て)
│  ├─ board.ts       盤面定義・マス効果解決
│  └─ rules.ts       賞金計算・勝敗判定
├─ ai/            評価層
│  ├─ evaluator.ts   お題+回答 → スコア/コメント(Worker 経由)
│  ├─ cpuPlayer.ts   CPU 回答生成(Worker 経由)
│  └─ mock.ts        オフライン用モック評価器
├─ components/    表示層(盤面・カード・HUD・演出)
└─ data/          topics.json・board.json
```

- reducer が唯一の状態変更点。UI は state を描画し、アクションを発行するだけ。
- **評価器はインターフェース `Evaluator` で抽象化**(旧 IEvaluator 思想の継承)。Gemini 実装とモック実装を差し替え可能とし、API なしでゲーム全体をテストできるようにする。
- game/ 層は React 非依存のため、ルール変更と単体テストが容易。

### 状態遷移(useReducer によるステートマシン)

```
Title → Setup → [ターンループ]
  TurnStart(カメラ移動)
  → AwaitingAnswer(入力 or CPU 生成中、タイマー進行)
  → Evaluating(採点中演出)
  → ShowingResult(スコア発表)
  → Moving(コマ移動アニメ)
  → CellEffect(マス効果)
  → 次プレイヤーへ / 全員ゴールなら → Result
```

## サーバー・Gemini 連携

### Worker エンドポイント

- `POST /api/evaluate` — お題+回答 → `{score: 1-6, comment: string}`
- `POST /api/cpu-answer` — お題+CPU 性格 → `{answer: string}`

### Gemini 呼び出し

- モデルは **gemini-2.5-flash**(旧設計の 1.5 系は廃止済み)。
- **Structured Output(`responseSchema`)で JSON スキーマを強制**する。旧設計で問題だった JSON パース失敗はこれでほぼ解消する。
- API キーは Worker の Secret で管理し、クライアントには一切露出しない。
- 悪用対策: Worker 側で IP 毎の簡易レート制限(毎分 10 回程度)と回答文字数上限を設ける。

### プロンプト方針(放送作家プロンプトの継承)

- 採点: 「あなたは辛口放送作家。お題への回答を 1〜6 で採点し、短いツッコミを返す」
- CPU 回答生成: 性格パラメータを織り込んだ回答生成プロンプト。

## エラー処理

- 評価リクエストはタイムアウト 10 秒 → 自動で 1 回リトライ → それでも失敗なら `score=3 / comment="電波の関係で審査員が聞き取れなかったらしい…"` のフォールバック値でゲームを続行する(UI を止めない)。
- 手動の「もう一度審査」ボタンも表示する。
- CPU 回答生成の失敗時は、ローカルの定型回答リストからフォールバックする(ゲームが止まらない)。

## データ

- `topics.json`: 既存資産(`data/topics.json`)を流用。id / カテゴリ / 難易度 / お題文。
- `board.json`: マス配列(種別 + 効果値 + 盤面座標)。

## テスト

- game/ 層: Vitest による純ロジック単体テスト(移動・賞金計算・勝敗判定)。
- 通し確認: モック評価器で API なしの全画面プレイを可能にし、Claude 自身がブラウザで動作検証する。

## デプロイ

- Cloudflare Pages(app) + Cloudflare Workers(worker)。無料枠内で運用。
- API キーは `wrangler secret` で登録。
