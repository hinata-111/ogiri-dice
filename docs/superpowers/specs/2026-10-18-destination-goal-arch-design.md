# 目的地だけに現れるゴールアーチ

ユーザー承認済み: 目的地の場所に、地名入りの小さなゴールアーチを一つ置く。目的地に設定されている間だけ表示し、切り替わると元の地名表示に戻す。朱色を控えめに使い、既存の街並みに合わせる。

## 表示

- 既存の目的地ラベルを、地名と小さな「ゴール」の文字を備えるアーチに置き換える。
- 二本の柱の間に到着マスがくるよう、既存のマス座標へ配置する。街並みの背景画像はそのまま使う。
- アーチは静止したクリーム色・朱色の小さな立体風パーツとする。ライト、旗、カーペット、発光、アニメーションは追加しない。上部UIは変更しない。
- アーチは現在の目的地一か所のみ。目的地の変更・解除・ゲーム終了時に以前の場所は通常表示へ戻る。
- 見回し・目的地表示・縮尺変更でもマスへの位置合わせを維持する。文字は通常のラベルと同様に読める大きさを保つ。
- コマと進路選択を優先し、アーチはクリック・ドラッグを遮らない。

## 実装範囲と検証

`app/src/components/map/` の描画だけを変更する。ゲームのreducer、ルール、Worker、マップデータ、背景画像は変更しない。ローカル・オンラインは共通のTokyoBoardで表示する。

目的地の切り替え・解除・ゲーム終了時の表示を既存コンポーネントテストで確認する。アプリ全テスト、build、oxlintを実行し、ブラウザでPC・縦画面の見た目と操作を確認する。コミット・公開はしない。
