# 全員の状況を常にまとめて表示する

ユーザー依頼: 「みんなの状況」は全員分を一か所にまとめ、常時表示したい。

- ゲーム開始後は画面上部に全員の一覧を常設する。P1〜P4の固定順で、色/番号・名前・所持金・順位・到着回数・進行状況を表示する。
- 通常回答は全員の回答中/提出済み/採点中/得点を表示し、P1だけを手番扱いしない。個別の移動・追加お題・到着では操作中の人を強調する。
- 一覧はマップ/回答/採点/結果/ルールの各表示とは別の上部領域に置く。ゲーム中のモーダルや回答窓で隠れず、操作領域と重ならない。
- 「みんなの状況」を開くボタンと既存ダイアログ、現在手番の人だけを表示するカードを置き換える。初期画面/設定画面には表示しない。
- PCは横並び、縦長スマホは2列で全員分を収める。短い画面やキーボード表示時はコンパクトにし、常に全員の名前と所持金を見られる。
- 一覧は状態を描画するだけ。reducer、共有データ、採点、期限、オンライン操作/通信に変更は加えない。

検証: 開始待ち・回答・採点・結果・移動・追加お題・到着・ゲーム終了での常設、4人/CPU/長い名前、所持金の更新、固定順、全員同時回答と個別手番の強調、PC/スマホ幅の配置を確認する。
