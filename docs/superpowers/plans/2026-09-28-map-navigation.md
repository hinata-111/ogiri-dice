# Map Navigation Implementation Plan

**Goal:** 地図を自由に見回し、現在地へ戻って少ない操作で移動できるようにする。

**Architecture:** `components/map/useMapCamera.ts` に表示専用カメラを分離する。`TokyoBoard.tsx` は既存の onStep のみを使い、reducer と Worker は変更しない。

**Tech Stack:** React / TypeScript / Vitest / Pointer Events

1. `app/src/components/map/TokyoBoard.test.tsx` に見回し・復帰・一本道・誤操作の回帰テストを先行追加し、`npm test -- src/components/map/TokyoBoard.test.tsx` で RED を確認する。
2. `useMapCamera.ts` に境界制限、追従の安全領域、ドラッグ、ピンチ、ホイール、キーボード、表示ショートカットを実装する。ゲーム状態は参照のみとする。
3. `TokyoBoard.tsx` に統合し、全体地図の強制スクロールを廃止。マス詳細と一本道の即時移動を追加し、`tokyo-board.css` に画面サイズ別の操作領域を定義する。
4. 回帰テストを GREEN にする。`App.test.tsx` のプレイ経路も新しい一本道ボタンに合わせる。
5. `npm test`、`npm run build`、`npm run lint` を実行する。ローカルブラウザで表示と操作を確認し、差分を見直す。コミット・公開は行わない。
