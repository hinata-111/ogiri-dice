# マス配置と経路の折れ返しを整理

ユーザー依頼: マスの並びと道がジグザグに見えるため、直線または大きな緩いカーブで経路を追いやすくする。

## 変更範囲

- `app/src/components/map/art-layout.ts` と対応テストに限定。着手時にこの2ファイルの既存差分がないことを確認。他の未コミット・未追跡の変更を保持した。
- 各路線の多数の折れ点を、直線または1本の緩やかな二次曲線に置き換える。
- 同じ曲線から道の描画・マスの等間隔配置・交差判定を導出し、マス・コマ・クリック領域の中心を一致させる。
- 拠点位置、マス数、隣接関係、色、reducer、Worker、生成マップデータ、背景画像は変更しない。既存の2か所の立体交差を維持する。
