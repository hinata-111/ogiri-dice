# 家庭用ゲームの実画面分析

調査日: 2026-09-25。企業公式ページ掲載のゲーム画像をブラウザで目視した記録。

対象はゲーム内画面であり、販売サイトの装飾ではない。画像の観察と、本作向けの提案を区別する。寸法のピクセル計測、アニメーション速度、ゲーム本体での操作検証は行っていない。

## R01 桃鉄ワールド：移動中

[公式あそびかた](https://www.konami.com/games/momotetsu/world/play.php) / [原画像1280×720](https://img.konami.com/games/momotetsu/world/img/play/ss01_02.webp)

![桃鉄ワールドの移動中](https://img.konami.com/games/momotetsu/world/img/play/ss01_02.webp)

位置で読む注釈:

1. 右上：白い面の「あと18マス」。地図の風景より強い明暗差を与えている。
2. 中央：移動主体が地図の中央付近にある。
3. 地図全体：経路とマスは明確な輪郭を持つ。地名は白い小さな面に載る。
4. 右端：画面外の対象を示す方向付きのアイコンがある。静止画のみでは各対象の全仕様は確定しない。

設計への示唆: 移動中に重要なのは盤面と残り歩数。巨大な常設順位パネルで盤面幅を奪わず、補助情報を端へ配置する。

## R02 桃鉄ワールド：物件選択

[公式あそびかた](https://www.konami.com/games/momotetsu/world/play.php) / [原画像1200×675](https://img.konami.com/games/momotetsu/world/img/play/ss01_06.webp)

![桃鉄ワールドの物件選択](https://img.konami.com/games/momotetsu/world/img/play/ss01_06.webp)

位置で読む注釈:

1. 上端：名前・所持金を一つの帯にまとめる。
2. 中央上：リストの選択行が橙色の帯と左側のカーソルで明示される。
3. 中央下：選択中の対象の説明をリストとは別枠に置く。
4. 下端：やめる・まとめ買い・買うに入力記号を添える。

設計への示唆: 選択対象、説明、確定操作は別の役割。全選択肢を同じ強さのカードにしない。方向候補も、注目中・確定済み・操作可能を区別する。

## R03 桃鉄ワールド：目的地の抽選表示

[原画像1280×720](https://img.konami.com/games/momotetsu/world/img/play/ss01_01.webp)

![桃鉄ワールドの目的地表示](https://img.konami.com/games/momotetsu/world/img/play/ss01_01.webp)

位置で読む注釈: 左に目的地リスト、中央に地球儀、右に案内役。選ばれている一行を色で強調する。これは通常移動と別の場面構成である。

設計への示唆: 発表の見せ場は専用の構成を使える。すべての画面に共通HUDを全面表示する必要はない。案内役や抽選リスト自体の採用は未決定。

## R04 マリオパーティ ジャンボリー：サイコロの場面

[公式スゴロクの島](https://www.nintendo.com/jp/switch/a7hla/sugoroku/index.html) / [原画像1920×1080](https://www.nintendo.com/jp/switch/a7hla/assets/img/sugoroku/poster_battle.webp)

![マリオパーティのサイコロ場面](https://www.nintendo.com/jp/switch/a7hla/assets/img/sugoroku/poster_battle.webp)

位置で読む注釈:

1. 左上：スターまでの距離。右上：ターン数。
2. 中央：キャラクターとサイコロに大きく面積を使う。
3. 下端：各プレイヤーの順位・資源・識別情報がまとまる。
4. 背景：奥の風景のぼかしに対して、主役と数値は明瞭。

設計への示唆: 常時情報を周辺に置き、中央をその瞬間の遊びに使う。キャラクター画像の識別力は高いが、本作のコマの外観をこの時点で決める根拠にはしない。

## 横断した設計判断

| 観察 | 本作に取り入れる案 | そのまま移さないもの |
|---|---|---|
| 遊びの主役を中央に置く | 移動は盤面、回答はお題、採点は回答を中央へ | 3D表現やキャラクターそのもの |
| 場面で情報量が変わる | 部品ごとに表示フェーズを定義する | 常に4人の詳細を表示する固定レイアウト |
| 選択にカーソルと面を使う | フォーカスと確定を別状態にする | 桃型カーソルや固有意匠 |
| 説明と入力ガイドが独立する | 対象説明・決定・戻るを決まった領域へ | SwitchのA/B表記をPCに表示すること |

参考作品の画像は出典付きの比較資料。ゲーム用素材として取り込まない。上記静止画から、操作音、選択アニメーション、フォーカス移動規則、全画面に共通する挙動は断定できない。

Switch本体のHOME画面は今回の部品設計の根拠に含めていない。ゲームの選択画面とは役割が異なり、独立した実画面確認が必要。

## 前案から撤回する前提

- AI生成ボードは不採用。切り抜きやトレースによる部品化もしない。
- 紙・切符の装飾、旅行かばんコマ、特定の色値・書体を既定路線にしない。
- 地図を2D上面SVGで描く決定、HTML/CSSで全体を構成する決定をしない。
- 見た目に必要な部品・状態・演出が固まるまで、本番描画方式を選定しない。
